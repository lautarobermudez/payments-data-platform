# Contributing

This is a portfolio project, but it is kept like a real one.

- **Branches:** work on a feature branch and open a pull request into `main`; CI must be green.
- **Commits:** short imperative subject (`Add cost-centre trigger`), one logical change each.
- **Database changes:** add a new numbered script in `db/` instead of editing an applied one, and cover the new rule with a query in `db/tests/data_quality.sql`.
- **Data:** never commit real data. Everything under `seed/data/` is generated by `seed/generate_seed.py`.
- **Checks before pushing:** `make test` (unit tests and data-quality rules).
